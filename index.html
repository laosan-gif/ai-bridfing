OpenAI 公布文本水印方案，API 可自愿开启

在回应欧盟 AI Act 文本溯源要求的公告中，OpenAI 宣布全球 API 客户可为部分模型选择开启 textGrain 文本水印，API 默认关闭。欧盟地区符合条件的 ChatGPT 与 Codex 文本输出将在未来数周逐步加入水印。
